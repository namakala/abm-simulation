Stress Buffering — Mediation of Stress Through Resources

Overview

This demo applies the Baron & Kenny mediation framework to the stress buffering phase. We vary current_stress [0, 1] while holding all other state constant, then measure the three causal paths:

  • a-path: stress → resources (negative coefficient — stress depletes resources)
  • b-path: resources → buffering (positive coefficient — resources enhance coping capacity)
  • c’-path: stress → buffering | resources (residual direct effect)

Mediation is confirmed when indirect_effect = a × b ≠ 0.

# Draw nodes
def draw_node(pos, label, color="#3498db", size=0.3):
    circle = plt.Circle(pos, size, color=color, ec="black", linewidth=2, zorder=5)
    ax.add_patch(circle)
    ax.text(pos[0], pos[1] - size - 0.4, label, ha="center", fontsize=11, fontweight="bold")

# Draw arrows
def draw_arrow(start, end, label, coef, color="black", offset=(0, 0)):
    start_adj = (start[0] + offset[0], start[1] + offset[1])
    end_adj = (end[0] + offset[0], end[1] + offset[1])
    arrow = FancyArrowPatch(
        start_adj, end_adj,
        arrowstyle="->,head_width=0.15,head_length=0.2",
        color=color, linewidth=2,
        connectionstyle="arc3,rad=0",
    )
    ax.add_patch(arrow)
    mid = ((start_adj[0] + end_adj[0]) / 2, (start_adj[1] + end_adj[1]) / 2)
    ax.text(mid[0], mid[1] + 0.3, f"{label}\n(coef={coef})", ha="center", fontsize=9,
            bbox=dict(boxstyle="round,pad=0.2", facecolor="white", alpha=0.8))

Observed Patterns

  • a-path (stress → resources, coefficient = -0.008): each unit increase in stress reduces resources by 0.008. This is the stress-depletion effect.
  • b-path (resources → buffering, coefficient = 0.5): each unit of remaining resources produces 0.5 units of buffering strength.
  • c’-path (stress → buffering | resources, coefficient = -0.2): even after accounting for resources, stress has a residual negative effect on buffering.
  • Indirect effect: a × b = -0.004 ≠ 0. This confirms partial mediation: stress affects buffering both directly (c’) and indirectly through resource depletion (a × b).
  • Social support acts as a parallel mediator: its efficacy scales the buffering path independently.
