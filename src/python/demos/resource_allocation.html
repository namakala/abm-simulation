Resource Allocation — PF Regeneration and Softmax Dynamics

Overview

This demo examines the resource allocation phase under four parameter scenarios. Each scenario runs 30 daily iterations and observes resource regeneration, softmax allocation weights, and PF efficacy trajectories.

The theory predicts:

  • Regeneration: R' = base_regeneration × (1 − R) × affect_mult × resilience_mult. Low resources regenerate faster; high R plateaus.
  • Softmax temperature: high T → near-uniform allocation; low T → winner-take-most (the factor with highest efficacy gets most resources).
  • Diminishing returns: PF efficacy gains shrink as efficacy approaches 1.0.

N_DAYS = 30
BASE_REGENERATION = 0.1
IMPROVEMENT_RATE = 0.1

scenarios = {
    "High R + default T": {"resources": 0.8, "temperature": 1.0, "efficacies": {f: 0.5 for f in _FACTORS}},
    "Low R + default T":  {"resources": 0.2, "temperature": 1.0, "efficacies": {f: 0.5 for f in _FACTORS}},
    "High R + high T":    {"resources": 0.8, "temperature": 5.0, "efficacies": {f: 0.5 for f in _FACTORS}},
    "Varied starting PF": {"resources": 0.5, "temperature": 1.0, "efficacies": {"social_support": 0.9, "family_support": 0.3, "formal_intervention": 0.5, "psychological_capital": 0.2}},
}

all_records = []
trajectories = {}

for scenario_name, params in scenarios.items():
    state = {
        "resources": params["resources"],
        "affect": 0.0,
        "resilience": 0.5,
        "protective_factors": dict(params["efficacies"]),
    }
    config = {
        "base_regeneration": BASE_REGENERATION,
        "softmax_temperature": params["temperature"],
        "protective_improvement_rate": IMPROVEMENT_RATE,
    }

    efficacies_traj = {f: [] for f in _FACTORS}
    rng = Generator(PCG64(42))

    for day in range(N_DAYS):
        out = run_phase(state, config, rng)
        obs = out["observation"]
        for f in _FACTORS:
            state["protective_factors"][f] = obs["efficacies_after"][f]
        state["resources"] = out["state_delta"].get("resources", state["resources"])
        state["affect"] *= 0.95  # gentle affect decay

        all_records.append({
            "scenario": scenario_name,
            "day": day,
            "regeneration_amount": obs["regeneration_amount"],
            "allocation_weights": obs["allocation_weights"],
            "resources_after": state["resources"],
            **{f"pf_{f}": obs["efficacies_after"][f] for f in _FACTORS},
            **{f"weight_{f}": obs["allocation_weights"].get(f, 0) for f in _FACTORS},
        })
        for f in _FACTORS:
            efficacies_traj[f].append(obs["efficacies_after"][f])

    trajectories[scenario_name] = efficacies_traj

df = pd.DataFrame(all_records)
corr_vars = ["regeneration_amount", "resources_after",
             "pf_social_support", "pf_family_support",

for scenario_name in scenarios:

    g.map_diag(sns.kdeplot, fill=True)
    g.fig.suptitle(f"Scenario: {scenario_name}", y=1.02, fontsize=12)

fig, axes = plt.subplots(2, 2, figsize=(10, 8))
colors = ["#3498db", "#e74c3c", "#2ecc71", "#f39c12"]

Observed Patterns

  • Regeneration is inversely proportional to current resources (diminishing returns). Low-R scenarios show larger regeneration spikes.
  • Softmax temperature: T=5 produces near-uniform allocation weights across PFs; T=1 concentrates resources on high-efficacy factors.
  • Varied starting PF: the social_support factor (initially 0.9) receives the largest allocation share due to softmax weighting, reinforcing its lead (rich-get-richer).
  • Diminishing returns: PF efficacy growth slows as each factor approaches 1.0, consistent with Δe_f ∝ (1 − e_f).
  • Resource conservation ensures resources stay within [0, 1] and a preservable fraction prevents complete depletion.
